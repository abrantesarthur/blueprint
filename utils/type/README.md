# @blueprint/type-utils

Generic, dependency-free TypeScript helpers for typed object/array manipulation,
conversions, and shared type definitions.

- **Typed object/array helpers** — `getKeys`, `getEntries`, `fromEntries`, `groupBy`, `indexBy`, `uniqueBy`.
- **Conversions** — `stringToInt32`, `uuidToInt32`, `toYyyymmddInt`, `toDateString`, `toHHMM`, `toTimeString`, `toLocalDate`.
- **Time-format guards** — `assertValidTimeFormat`, `isTimeAligned`.
- `types` — shared generic type helpers (e.g. `RequiredField`).
- `regex` — shared generic regex patterns.
